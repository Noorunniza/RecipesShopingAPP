# 🍽️ Recipe Shopping App (SwiftUI)

This is a simple SwiftUI application that displays a list of recipes and allows users to add items to a cart. The app uses `ObservableObject` and `@Published` properties to manage shared state across views.

---

## 🔥 Features

- Browse recipes in a list
- View detailed recipe screen
- Add items to cart
- View cart in a separate tab
- Remove items using swipe delete
- Shared `CartManager` using ObservableObject

---

## 📱 Screens Used

| Screen | Description |
|--------|------------|
| **RecipiesUIView** | Shows list of recipes |
| **RecipieDetails** | Shows selected recipe details + Add to Cart |
| **Cart Tab** | Displays added items & supports delete |
| **ContentView** | Main tab navigation |

---

## 🛠️ Technologies

- **SwiftUI**
- **ObservableObject + State Management**
- **NavigationView & NavigationLink**
- **List & ScrollView UI**
- **MVVM-like architecture**
